先看完整数据流

令 packed 序列长度为 T。T 随视频帧数、分辨率、音频长度和输入内容变化，所以不固定；H3 的 block 主干始终把每个 token 表示为 5,376 维。

X [T, 5376] → AdaLN 调制 → H [T, 5376] → QKV 投影 [T, 21504] → Q,K,V 各 [T, 56, 128] → Q/K RMSNorm + 3D MM-RoPE → packed non-causal self-attention → [T, 56, 128] → flatten [T, 7168] → output projection [T, 5376] → X1 = X + gate_msa ⊙ attn_out → AdaLN 调制 → H2 [T, 5376] → SwiGLU FFN: 5376 → 28672 → split 2×14336 → 14336 → 5376 → Xout = X1 + gate_mlp ⊙ ffn_out
主模型配置：hidden_size=5376、num_attention_heads=56、attention_head_dim=128、ffn_dim=14336。注意：H3 的注意力内部宽度 56×128=7168，大于 hidden_size 5376。

逐步展开真实矩阵形状

1

AdaLN：从 timestep 条件生成六组调制向量

输入 timestep embedding；每个 token 按 timestep / modality 索引选参数
›

每个主 block 有自己的 AdaLN 投影。官方配置的 timestep MLP 输出维度是 2,688；AdaLN 一次输出 96,768 个数，恰好是 3 modality × 6 组 × 5,376 hidden。

矩阵乘法（数学写法）

E_t [N_t, 2688] × W_adaln [2688, 96768] + b [96768] → A [N_t, 96768] → reshape [N_t, 3, 6, 5376]
PyTorch Linear 的 weight 通常以 [out_features, in_features] 存储，因此 checkpoint 参数张量对应 [96768, 2688]；上式 W 按数学乘法方向书写。

reshape 后的六组含义

modality 0: shift_msa [5376], scale_msa [5376], gate_msa [5376], shift_mlp [5376], scale_mlp [5376], gate_mlp [5376] modality 1: 同样六组 modality 2: 同样六组
官方代码把六组按 shift_msa、scale_msa、gate_msa、shift_mlp、scale_mlp、gate_mlp 排列。token 的 modality tag 和 timestep index 决定查哪一行。

若一次 forward 的 packed tokens 有 T 行，索引查表后，六个调制张量各自为 [T, 5376]。同一 timestep、同一 modality 的 token 可以复用同一行调制参数。

例如 4 个 token 的 modality tag： [video, audio, text, video] 索引表为每个 token 取对应的 (timestep, modality) 行 scale_msa_lookup → [4, 5376] shift_msa_lookup → [4, 5376] ……六组都如此
不要把 AdaLN 参数理解成 token 内容。它是由扩散 timestep 条件投影出的控制向量；索引步骤把相应控制向量分配给 packed 序列里的每个 token。三种 modality 的具体 tag 编码顺序应以所用版本的模型代码为准。
2

Norm1 + AdaLN：逐通道缩放、平移

残差流维持 [T, 5376]；归一化不改变矩阵形状
›

每个 token 的 5,376 个通道独立参与 RMSNorm 归一化，然后乘以 (1+scale_{msa})，再加 shift。

X [T,5376] → RMSNorm(X) [T,5376] H = RMSNorm(X) ⊙ (1 + scale_msa[T,5376]) + shift_msa[T,5376] → H [T,5376]

单个 token 的逐通道公式（i 为 token，j 为 hidden channel）

H[i,j] = RMSNorm(X[i,:])[j] × (1 + scale_msa[i,j]) + shift_msa[i,j] 其中 i ∈ [0,T)，j ∈ [0,5376)

这里的 scale、shift 都是长度 5,376 的向量，对应地调节该 token 的每一个隐藏通道。Norm 权重向量同样是 5,376 维。

3

QKV 投影：从残差宽度映射到注意力宽度

5376 → 3×7168；每个 7168 再拆成 56 个 128 维头
›

注意力每个头有 128 维，56 个头拼接后宽度为 7,168。所以 Q、K、V 的总投影宽度是 21,504。

H [T, 5376] × W_qkv [5376, 21504] → QKV [T, 21504] → split(last dim, [7168,7168,7168]) → Q [T,7168], K [T,7168], V [T,7168] → reshape → Q,K,V 各 [T,56,128]
输入通道
H = 5,376
每个 Q/K/V 输出宽度
56 heads × 128 = 7,168
融合 QKV 输出宽度
3 × 7,168 = 21,504
逻辑矩阵 W 按输入维×输出维表示为 [5376,21504]。若查看 PyTorch Linear 的 weight 参数存储，常见形状是 [21504,5376]。原始 Diffusers 权重也可能分别存 Q/K/V 投影，运行时再融合。
4

Q/K RMSNorm + 3D MM-RoPE：处理每个头的内容和位置

Q、K、V 为 [T,56,128]；RoPE 只旋转每头的 96 个通道
›

Q/K RMSNorm

Q [T,56,128] → 每个 (token, head) 对 128 维归一化 K [T,56,128] → 同样处理 Norm 权重：每个 Q/K 通道向量 [128]

它让每个注意力头的 Q 和 K 在进入点积前按各自的 RMSNorm 规则归一化。V 不做这一步 Q/K 归一化。

3D MM-RoPE

位置坐标：每个 token 有 (t, h, w) rope_freq_dim = 16 / 轴 3 个轴 × 16 频率 × 每频率 2 个旋转通道 = 96 每头 128 维中：96 维参与旋转，32 维不旋转

RoPE 把时空位置信息注入 Q 和 K，使注意力分数能反映 token 的相对位置。频率表按时间、高度、宽度三轴构造。

形状保持不变：Q′, K′, V: [T,56,128]。

5

Packed self-attention：每个 token 从序列读取信息

概念上的注意力矩阵为 [56,T,T]；实现通常分块计算，不完整物化
›

对某个 head (h)，Q、K、V 的形状分别是 `[T,128]`。它先对 token 两两做 QK 点积，再对分数做 softmax，最后用概率加权 V。

每个 head h： Q′_h [T,128] × K′_hᵀ [128,T] → scores_h [T,T] / √128 → softmax(scores_h) = P_h [T,T] P_h [T,T] × V_h [T,128] → O_h [T,128] 56 个 head 合并：O [T,56,128] flatten heads → [T,7168]
cu_seqlens 的意义：它标出 packed batch 中每段序列的边界。若是一条 H3 请求，概念上可看作一个长度 T 的 attention document；若多个独立样本被打包，段与段之间不能互相注意。H3 主注意力是 full self-attention、non-causal；模态 token 位于统一 packed 序列中。

真实 kernel 通常按 tile 计算 score/softmax/value，不会把完整 `[56,T,T]` 保存到显存。这个矩阵是理解数学关系的概念形状。

6

Attention 输出投影 + 第一次门控残差

7,168 → 5,376，然后按 gate_msa 逐元素加回原 X
›
O [T,7168] × W_o [7168,5376] → attn_out [T,5376] X1 = X + gate_msa ⊙ attn_out X [T,5376], gate_msa [T,5376], attn_out [T,5376] → X1 [T,5376]

注意力结果回到残差流维度 5,376。`gate_msa` 也是逐 token、逐 hidden channel 的门控向量，控制注意力分支更新的大小。

7

Norm2 + AdaLN：准备 FFN 输入

结构与 Attention 前归一化类似，但使用 MLP 对应的 scale/shift
›
RMSNorm(X1) [T,5376] H2 = RMSNorm(X1) ⊙ (1 + scale_mlp[T,5376]) + shift_mlp[T,5376] → H2 [T,5376]

这一步把 Attention 更新后的状态重新归一化，再按 MLP 这一路的 AdaLN 参数逐通道调制。这里的 scale/shift 与步骤 2 的 Attention 参数不同。

8

SwiGLU FFN：扩展通道、门控非线性、压回残差宽度

5376 → 28672 → 两路各 14336 → 5376
›

FFN 对每个 token 独立做特征变换；这里不在 token 之间交换信息。第一层同时产生 gate 与 up 两路。

H2 [T,5376] × W_fc1 [5376,28672] → Z [T,28672] → split Z = [G | U] G [T,14336], U [T,14336] Y = SiLU(G) ⊙ U → Y [T,14336] Y [T,14336] × W_fc2 [14336,5376] → ffn_out [T,5376]
数学写法中的权重按 [in,out] 排列；PyTorch Linear weight 参数一般按 [out,in] 存储，因此 fc1 weight 常见为 [28672,5376]、fc2 weight 常见为 [5376,14336]。
9

第二次门控残差：得到 block 输出

FFN 分支输出乘 gate_mlp，再加回 Attention 后的 X1
›
Xout = X1 + gate_mlp ⊙ ffn_out X1 [T,5376], gate_mlp [T,5376], ffn_out [T,5376] → Xout [T,5376]

block 的输入输出形状一致，都是 `[T,5376]`。50 个主 Transformer blocks 依次堆叠时，一个 block 的 `Xout` 就是下一个 block 的 `X`。

阅读时记住三件事

残差流

一直是 5,376 维。两次子层都把结果投影回 5,376，再加回残差。

Attention

注意力宽度是 7,168。它由 56 个 128 维头组成；与 5,376 不同。

AdaLN

输出控制向量。每 token 查到六个 5,376 维向量，分别调制 Attention 与 FFN。

动态长度

T 不是模型常量。输入分辨率、视频帧数、音频长度和 packed layout 会改变 T。

关于多卡切分：上面是单个 block 的全局逻辑形状。TP/USP 下每张卡只持有切分后的权重或 token/head 分片，局部矩阵形状会变化；全局模型配置不变。若要画具体每卡矩阵，需要再指定 TP、Ulysses degree 和是否 padding。
