一直想有一个自己的地方，把学过的东西、踩过的坑沉淀下来。与其让笔记散落在各个角落，不如开一个博客，逼自己把知识整理成能讲清楚的文章——写作本身就是最好的学习方式。

这个博客目前的构成：

- **框架**：[Astro](https://astro.build)（官方 Blog 模板）
- **写作方式**：仓库里的 Markdown 文件，每篇文章一个 `.md`
- **托管**：GitHub Pages，推送后由 GitHub Actions 自动构建发布
- **地址**：先用 `echoes1984.github.io`，以后再绑定自己的域名

## 以后写什么

技术笔记、踩坑记录，偶尔写点随笔。第一版先解决「能写、能发布」，样式、分类、搜索这些以后慢慢加。

可以写 Markdown、代码块、公式和图片：

```python
def hello():
    print("Hello, blog!")
```
